# Фото

Сюди клади реальні фотографії Кароліни.

Головне фото для hero-блоку (кружечок на головній сторінці):
- Ім'я файлу: karolina.jpg (або .png)
- Рекомендований розмір: мінімум 640x640px, квадратне співвідношення
- Після додавання файлу онови index.html:
  розкоментуй рядок <img src="images/photos/karolina.jpg" ...>
  і прибери <span>Фото</span>-заглушку в .photo-circle
